# 初眠工具箱 (Chumian Toolbox)

一款包含 112 款真实可用工具的安卓工具箱应用。

## 功能分类

### 🔧 系统工具 (20款)
设备信息、电量信息、CPU监控、内存监控、存储信息、传感器查看器、振动测试、屏幕常亮、音量管理、亮度调节、夜间模式、应用管理、文件管理、存储清理、电池历史、应用使用统计、进程管理、分辨率/DPI、沉浸式状态栏、快捷设置

### 🏠 日常工具 (28款)
科学计算器、单位换算、货币换算、指南针、水平仪、量角器、屏幕尺子、手电筒、放大镜、镜子、二维码生成、二维码扫描、倒计时/秒表、世界时钟、日期计算、年龄计算、BMI计算、体脂率计算、密码生成器、随机数生成、抽签/骰子、颜色选择器、调色板、笔记/便签、待办清单、记账本、天气查询、翻译

### 🌐 网络工具 (15款)
网速测试、IP查询、端口扫描、Ping测试、DNS查询、Whois查询、网站状态检测、HTTP请求测试、网络信息、热点管理、蓝牙扫描、NFC读取、局域网扫描、域名解析、反向IP查询

### 🖼️ 图片工具 (14款)
图片压缩、格式转换、图片裁剪、图片旋转、图片滤镜、图片拼接、九宫格切图、图片转Base64、Base64转图片、图片取色器、分辨率修改、图片加水印、表情包制作、GIF分解/合成

### 💻 开发工具 (25款)
JSON格式化、XML格式化、HTML格式化、Base64编解码、URL编解码、哈希计算、AES加密、RSA加密、时间戳转换、正则测试、颜色代码转换、进制转换、ASCII码表、Unicode转换、代码行数统计、文本对比、文本去重、文本替换、大小写转换、简繁转换、字数统计、Markdown预览、SQL格式化、CSV查看器、JSON转换

### 🎵 影音工具 (10款)
音频格式转换、视频信息查看、视频转GIF、音频剪辑、铃声制作、文本转语音、语音转文字、音频频谱分析、噪音检测、音调检测

## 技术栈
- Flutter 3.x + Dart
- Material 3 主题（深色/浅色/跟随系统）
- Provider 状态管理
- SharedPreferences 本地存储

## 构建
通过 GitHub Actions 云端构建 release APK。
